📌 How to use these files:

  • All files are pure Scalable Vector Graphics (SVG), meaning you can scale them to any size (from a tiny 1-inch sticker to a giant shop billboard) without any pixelation or loss of quality.
  • You can open them directly in Adobe Illustrator, Photoshop, Figma, CorelDraw or send them straight to any printing press in Bangladesh.
  • These files are located in the brand-assets/ folder inside the project root, completely independent of the e-commerce website code.
