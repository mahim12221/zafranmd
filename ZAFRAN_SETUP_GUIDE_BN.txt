২. MongoDB ডেটাবেস সেটআপ ও লাইভ স্ট্যাটাস (সফলভাবে কানেক্টেড!)
================================================================================
অভিনন্দন! আপনি MongoDB Atlas-এ 0.0.0.0/0 সেট করেছেন এবং আপনার ডেটাবেসটি
সরাসরি লাইভ ক্লাউডের সাথে সফলভাবে কানেক্টেড (database: mongodb)। প্রাথমিক
প্রোডাক্টসমূহ সরাসরি আপনার ক্লাস্টার ডেটাবেসে সিড (সংরক্ষিত) হয়ে গেছে।

--------------------------------------------------------------------------------
VITE_BACKEND_URL নিয়ে বিস্তারিত সহজ নির্দেশনা:
--------------------------------------------------------------------------------
১. এটি কী?
   এটি ফ্রন্টএন্ড থেকে ব্যাকএন্ড এপিআই সার্ভারে রিকোয়েস্ট পাঠানোর অ্যাড্রেস।

২. কখন এটি খালি ("") রাখবেন?
   Render-এ যখন পুরো প্রজেক্টটি একসাথে চলবে (যেভাবে বর্তমান প্রজেক্ট সাজানো),
   তখন ফ্রন্টএন্ড ও ব্যাকএন্ড একই ডোমেইনে থাকবে। তখন VITE_BACKEND_URL খালি
   রাখাই সবচেয়ে ভালো এবং নিরাপদ। কারণ খালি থাকলে ব্রাউজার সরাসরি রিলেটিভ পাথ
   (/api/product/list) কল করে, ফলে কোনো CORS এরর আসার সুযোগ থাকে না।

৩. কখন এটি সেট করবেন?
   যদি ফ্রন্টএন্ড Vercel-এ এবং ব্যাকএন্ড Render-এ আলাদা করে হোস্ট করেন,
   তখন Vercel ড্যাশবোর্ডে VITE_BACKEND_URL = https://your-backend.onrender.com
   বসিয়ে দেবেন। আমাদের কোডে স্বয়ংক্রিয়ভাবে ট্রেইলিং স্ল্যাশ (/) ঠিক করার ফিল্টার
   দেওয়া আছে, তাই ভুল হওয়ার কোনো সুযোগ নেই।


ধাপ ১: MongoDB Atlas অ্যাকাউন্ট ও ক্লাস্টার তৈরি
১. https://www.mongodb.com/cloud/atlas ওয়েবসাইটে যান।
২. একটি ফ্রি একাউন্ট খুলুন অথবা লগইন করুন।
৩. Build a Database বাটনে ক্লিক করে M0 Free (Shared Sandbox) অপশন নির্বাচন করুন।
৪. Provider AWS এবং অঞ্চল Singapore বা Mumbai সিলেক্ট করে Create Cluster করুন।

ধাপ ২: ডেটাবেস ইউজার তৈরি
১. ক্লাস্টার তৈরির সময় আপনাকে Username ও Password দিতে বলবে।
   উদাহরণ:
   - Username: zafran_admin
   - Password: YourStrongPassword123 (পাসওয়ার্ডটি মনে রাখুন)
২. Create Database User বাটনে ক্লিক করুন।

ধাপ ৩: Network Access (IP Whitelist) কনফিগারেশন — অত্যন্ত গুরুত্বপূর্ণ!
ক্লাউড ডেপ্লয়মেন্ট থেকে কানেক্ট করতে এই ধাপটি আবশ্যক:
১. বাঁদিকের মেনু থেকে Security > Network Access-এ যান।
২. Add IP Address বাটনে ক্লিক করুন।
৩. ALLOW ACCESS FROM ANYWHERE বাটনে ক্লিক করুন (আইপি বক্সে 0.0.0.0/0 বসবে)।
৪. Confirm করুন।

ধাপ ৪: Connection String কপি করা
১. Deployment > Database-এ যান।
২. ক্লাস্টারের Connect বাটনে ক্লিক করুন।
৩. Drivers অপশন বেছে নিন (Node.js)।
৪. কানেকশন স্ট্রিং কপি করুন, যেমন:
   mongodb+srv://zafran_admin:<password>@cluster0.abcde.mongodb.net/?retryWrites=true&w=majority
৫. <password>-এর জায়গায় আসল পাসওয়ার্ড বসিয়ে দিন এবং শেষে ডেটাবেসের নাম /zafran দিন:
   mongodb+srv://zafran_admin:YourStrongPassword123@cluster0.abcde.mongodb.net/zafran?retryWrites=true&w=majority

৫. ওয়েবসাইট লাইভ ডেপ্লয়মেন্ট গাইডলাইন (Render & Vercel)
================================================================================

অপশন ক: Render.com-এ ডেপ্লয় (ফুলস্ট্যাকের জন্য সবচেয়ে সেরা ও সহজ)
১. https://render.com এ GitHub দিয়ে লগইন করুন।
২. New + > Web Service চাপুন।
৩. আপনার GitHub রিপোজিটরি (mahim12221/zafranmd) সিলেক্ট করুন।
৪. সেটিংস:
   - Name: zafran-store
   - Runtime: Node
   - Build Command: npm install && npm run build
   - Start Command: npm start
৫. Environment Variables সেকশনে .env ফাইলের মানগুলো যুক্ত করুন (MONGODB_URI ইত্যাদি)।
৬. Deploy Web Service এ ক্লিক করুন। কিছুক্ষণের মধ্যে লাইভ লিংক তৈরি হয়ে যাবে!

অপশন খ: Vercel-এ ডেপ্লয়
১. https://vercel.com এ যান এবং রিপোজিটরি ইমপোর্ট করুন।
২. ফ্রন্টএন্ড ডেপ্লয় করে এনভায়রনমেন্ট ভ্যারিয়েবলে VITE_BACKEND_URL যুক্ত করুন।

অপশন গ: কাস্টম ডোমেইন কানেক্ট করা
Render বা Vercel ড্যাশবোর্ডের Settings > Custom Domains-এ আপনার কেনা ডোমেইন
(যেমন: zafran.com বা zafranbd.com) লিখে DNS Records আপডেট করলেই নিজস্ব ডোমেইনে
ওয়েবসাইটটি লাইভ চালু হয়ে যাবে।
